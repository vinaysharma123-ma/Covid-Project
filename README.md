# 🦠 COVID-19 Data Analysis & Visualization

## 📌 Project Overview

This project focuses on analyzing global COVID-19 data to identify trends, patterns, and key insights related to confirmed cases, deaths, recoveries, active cases, and weekly growth. The analysis demonstrates practical **Data Analytics, Data Cleaning, Exploratory Data Analysis (EDA), and Data Visualization** skills using Python and Power BI.

## 🎯 Project Objectives

* Analyze the global spread and impact of COVID-19.
* Identify countries with the highest confirmed cases and death rates.
* Analyze recovery and mortality trends.
* Compare COVID-19 statistics across WHO regions.
* Identify countries with the highest 1-week growth.
* Detect and handle outliers in numerical variables.
* Create meaningful visualizations and dashboards for better decision-making.

## 🛠️ Tools & Technologies

* **Python**

* **NumPy** – Numerical analysis
* **Matplotlib & Seaborn** – Data visualization
* **Power BI** – Interactive dashboard creation
* **Jupyter Notebook**
* **Excel** – Data inspection and preprocessing

## 🔍 Key Analysis Performed

* Data cleaning and preprocessing
